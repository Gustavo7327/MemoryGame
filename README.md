# Jogo da Memória
Este jogo foi desenvolvido utilizando a API JavaFX e tem como tema animes no geral. Utilizei maven para gestão de dependências do projeto.

### Ao baixar o projeto, execute esse comando para instalar as dependências:
```maven
mvn clean install
```
### E para rodar a aplicação, execute:
```maven
mvn javafx:run
```
